# Texture atlas

Edit `atlas.ppm` with an image editor that supports PPM, or replace it with another P3/P6 PPM file.

- Canvas: 160 x 16 pixels
- Layout: ten 16 x 16 tiles in one horizontal row
- Tile order is documented in the repository README
- Keep the canvas dimensions and tile boundaries unchanged

If this file is missing or has an unsupported format, the game falls back to its built-in generated atlas.
